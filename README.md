# Flip-My-Landscape
Use this to flip the orientation of your Kindle in Landscape mode. The Kindle must be jailbroken first.

This project provides a standalone scriptlet that allows you to flip your Kindle's reading layout 180 degrees into Reverse Landscape mode. It requires no KUAL or extensions folder placement; it runs as a native-looking book right from your Kindle library using the modern Scriptlet (SH_Integration) framework.

# Instructions

1. Connect your jailbroken Kindle to your computer using a USB cable.
2. Open the Kindle drive, go to the 'documents' folder, and drop the 'toggle_landscape.sh' file inside it.
3. Safely disconnect your Kindle from your computer.
4. Go to your Kindle Library and tap the newly appeared "Flip My Landscape" book item.
5. Open any book you want—it will now be open in the reversed horizontal view.

Note: To flip it back to standard landscape, just return to the library and tap the "Flip My Landscape" item again. Also, every time you tap the "Flip My Landscape" item, press-and-release the power button before opening any books.
