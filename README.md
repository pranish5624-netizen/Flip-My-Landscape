# Flip-My-Landscape
Use this to flip the orientation of your Kindle in Landscape mode. The Kindle must be jailbroken first.

This project provides a standalone scriptlet that allows you to flip your Kindle's reading layout 180 degrees into Reverse Landscape mode. It requires no KUAL or extensions folder placement; it runs as a native-looking book right from your Kindle library using the modern Scriptlet (SH_Integration) framework.
